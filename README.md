# Smart Task Manager

A Python and SQLite portfolio project with a terminal interface and a FastAPI REST API. It demonstrates password hashing, relational persistence, user-scoped task management, data validation, and automated tests. This is a learning project, not a production service.

## Features
- User registration with randomly salted PBKDF2-SHA256 password hashes
- Login for the terminal program and HTTP Basic authentication for the local API
- Full task CRUD: create, list, read, edit, and delete
- User-isolated queries: one user cannot access another user's tasks
- Automated tests for authentication, validation, task ownership and CRUD
- Interactive API documentation generated by FastAPI

## Run on your machine

Requires Python 3.10 or newer.

    python -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    python main.py

For the HTTP API, instead run:

    uvicorn api:app --reload

Then open http://127.0.0.1:8000/docs to try the API.

On Windows, activate the virtual environment using .venv/Scripts/activate.

## Example API usage

Start the API as above, then use a separate terminal:

    curl -X POST http://127.0.0.1:8000/users -H 'Content-Type: application/json' -d '{"username":"demo","password":"example-password-123"}'
    curl -u demo:example-password-123 -X POST http://127.0.0.1:8000/tasks -H 'Content-Type: application/json' -d '{"title":"Prepare portfolio","priority":"high"}'
    curl -u demo:example-password-123 http://127.0.0.1:8000/tasks

Available routes: POST /users, GET /tasks, POST /tasks, GET /tasks/{task_id}, PUT /tasks/{task_id}, DELETE /tasks/{task_id}.

## Project structure

- database.py: SQLite connection, migrations-free schema creation
- user.py: registration and password hashing/verification
- task.py: user-owned SQL CRUD operations
- main.py: interactive CLI
- api.py: HTTP endpoints and request validation
- tests/: independent unit and HTTP integration tests

## Testing

    python -m unittest discover -s tests -v

## Security and limitations

- HTTP Basic sends credentials on each request. **Use the API locally only.** Any remote deployment requires HTTPS, request throttling, logging, secret management and additional security reviews.
- The database schema changes from the original prototype. **Old tasks.db files are not automatically migrated.** Back up existing local data and start with a new database. You can set the TASK_MANAGER_DB environment variable to use a separate SQLite file.
- Password reset, sessions, audit logging and production deployment are out of scope.
- The project demonstrates principles in a small app; it is not a production authentication solution.
